Cart2Insights: Decoding E-Commerce Performance

An end-to-end data analytics project on the Olist Brazilian E-Commerce dataset, taking ~1.3M raw records across 9 relational tables from messy CSVs to a fully interactive business intelligence dashboard.

What this project covers:

Data Cleaning & Preprocessing — Identified and resolved real data quality issues across 9 tables: 261,831 duplicate rows removed, invalid geographic coordinates filtered, non-unique primary keys resolved with surrogate keys, and inconsistent categorical values standardized.

Relational Database Design — Built a fully normalized MySQL database with enforced primary/foreign key constraints across all 9 tables, based on a mapped ER diagram.

Feature Engineering — Derived business-relevant features including delivery delay, order value, and repeat customer indicators.

Exploratory Data Analysis — Univariate, bivariate, multivariate, trend, correlation, and distribution analysis using SQL and Python, uncovering measurable relationships between delivery performance and customer satisfaction.

SQL-Powered Business Intelligence — 20+ SQL queries (joins, subqueries, aggregations, CASE logic) answering real business questions across sales, customers, sellers, and delivery performance.

Interactive Dashboard — A 6-section Streamlit dashboard (Business Overview, Sales, Customer, Seller & Product, Delivery, and Customer Experience analysis), visualized with a mix of bar, pie, donut, treemap, gauge, and scatter charts, connected live to the MySQL database.

Business Insights — Data-backed findings and recommendations covering customer retention, regional delivery disparities, seasonal demand patterns, and satisfaction drivers.

Tech stack: Python (Pandas, SQLAlchemy), MySQL, Streamlit, Plotly
